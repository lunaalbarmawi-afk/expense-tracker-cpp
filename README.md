# Smart Budget Manager

A beginner C++ console application that helps users track their expenses and manage a simple budget.

## Features

- Enter a custom number of expenses.
- Reject negative expense values.
- Calculate total expenses.
- Calculate the remaining budget.
- Calculate the average expense.
- Find the largest expense.
- Display a warning when expenses exceed the budget.
- Use dynamic memory allocation with `new` and `delete[]`.

## Technologies

- C++
- Arrays and pointers
- Loops and conditional statements
- Dynamic memory allocation

## Budget

The initial budget is set to 200.

## How to Run

1. Download or clone this repository.
2. Open `main.cpp` in a C++ IDE, such as Visual Studio.
3. Compile and run the program.
4. Enter the number of expenses and their values when prompted.

## Learning Goals

This project was created to practice fundamental C++ programming concepts through a practical budgeting application.
